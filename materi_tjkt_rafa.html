01

Intrusi Command Prompt

> Command Prompt (CMD) adalah antarmuka baris perintah di Windows untuk menjalankan perintah jaringan dan sistem secara langsung.
ipconfig
Lihat konfigurasi IP & refresh DHCP
/all — Tampilkan detail lengkap
/release — Lepas alamat IP
/renew — Dapatkan IP baru
/flushdns — Bersihkan cache DNS
ping
Mengecek koneksi ke alamat IP atau domain
-t [alamat] — Ping terus menerus (CTRL+C stop)
-n [jml] [alamat] — Jumlah ping. Contoh: -n 10
-l [ukuran] — Ukuran paket (byte). Contoh: -l 1000
-4 / -6 — Paksa IPv4 / IPv6
-a [IP] — Cari hostname dari IP
Gabungan: ping -n 5 -l 1000 google.com
tracert
Melacak rute paket data menuju tujuan
Contoh: tracert google.com
netstat
Menampilkan koneksi jaringan aktif & port
-an — Tampilkan semua koneksi & port
Contoh: netstat -an
nslookup
Mengecek informasi DNS dari sebuah domain
Contoh: nslookup google.com
arp
Menampilkan & memodifikasi tabel ARP
-a — Tampilkan semua entri ARP
Contoh: arp -a
hostname
Menampilkan nama komputer saat ini
Contoh: hostname
netsh
Konfigurasi jaringan tingkat lanjut
Contoh: netsh wlan show profiles

Aplikasi Virtual

VirtualBox
OPEN SOURCE · ORACLE
Software virtual gratis buatan Oracle untuk menjalankan sistem operasi (VM) di dalam komputer fisik.
Gratis & open-source Multi-OS Cocok pemula Aman untuk eksperimen Belajar jaringan
VMware
ENTERPRISE · BROADCOM
Platform virtualisasi enterprise menggunakan hypervisor untuk membagi sumber daya hardware menjadi beberapa VM.
Performa stabil Fitur enterprise Skala besar Cloud computing Snapshot & Clone
Proxmox
BARE METAL · LINUX
Platform virtualisasi berbasis Linux untuk mengelola VM dan container langsung di atas hardware (bare metal).
Gratis & open-source Web panel VM + Container High Availability Private cloud
